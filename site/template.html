Claude Code, installed via the skills CLI 
claude mcp add --transport {{MCP_TRANSPORT}} --header "{{MCP_HEADER}}: $MSU_OPENAPI_KEY" \
  {{MCP_SERVER}} {{MCP_URL}}
Codex CLI — .codex/config.toml 
[mcp_servers.{{MCP_SERVER}}]
url = "{{MCP_URL}}"
env_http_headers = { "{{MCP_HEADER}}" = "MSU_OPENAPI_KEY" }
Cursor — .cursor/mcp.json 
{
  "mcpServers": {
    "{{MCP_SERVER}}": {
      "url": "{{MCP_URL}}",
      "headers": {
        "{{MCP_HEADER}}": "${env:MSU_OPENAPI_KEY}"
      }
    }
  }
}
